## Corrected gate

The gate permits local research reads of any public submission and permits
`kernel_sources` that provide models or hidden-data-independent artifacts. It
rejects a competition notebook only when executable code discovers a mounted
visible `submission.csv` for use as the hidden parent. It also requires:

- exact normalized lineage to the scored D29 notebook;
- no new fixed public row/ID contract beyond that scored lineage;
- bounded PF and visible-prefix runtime settings;
- a completed private GPU run;
- sample-ordered unique IDs, finite predictions, matching audit hashes, and a
  clean log;
- exact remote source, metadata, and output hashes immediately before submit.
