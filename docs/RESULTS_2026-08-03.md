## Safety contract

Every eligible private Version 1 must:

- preserve every upstream modelling code cell exactly;
- add only attribution markdown and one dynamic output-audit cell;
- use the upstream runtime and input metadata with internet disabled;
- recompute predictions from competition data and model artifacts;
- produce exactly the hidden sample row count in official ID order;
- contain unique IDs and finite `tvt` values;
- match its downloaded submission and prediction SHA-256 values;
- have no fatal log marker;
- pass an immediate remote source, metadata and output recheck before submit.

Competition submissions remain at `0 / 5` until the private runs complete and
pass this contract. Adjacent competition refs must be separated by at least
30 minutes.
